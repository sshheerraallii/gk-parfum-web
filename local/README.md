# Run on your Windows PC

1. Install Node.js 22 LTS: https://nodejs.org
2. Install PostgreSQL 16: https://www.postgresql.org/download/windows/ (remember the password you set; keep port 5432)
3. Double-click setup-local.bat (once)
4. Double-click start-local.bat (every time)

Admin: http://localhost:9000/app  -  Website: http://localhost:3000
